# 01 - Amazon Route53 DNS Architecture

Managed Domain Name System (DNS) web service operating with 100% SLA availability.

- **Public Hosted Zone**: Internet-resolvable DNS records.
- **Private Hosted Zone**: VPC-internal DNS records.
- **ALIAS Record**: Route53-specific record pointing directly to AWS resources (ALB, CloudFront, S3).
