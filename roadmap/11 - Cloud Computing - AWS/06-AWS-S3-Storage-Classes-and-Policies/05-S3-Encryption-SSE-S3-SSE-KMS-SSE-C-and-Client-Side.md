# 05 - S3 Encryption Options

- **SSE-S3**: Keys managed by Amazon S3 (AES-256).
- **SSE-KMS**: Keys managed in AWS Key Management Service (provides audit log of key usage).
- **SSE-C**: Keys managed by customer (provided per HTTP header).
