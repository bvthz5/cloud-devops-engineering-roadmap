# 01 - S3 Architecture, Buckets & Objects

Amazon Simple Storage Service (S3) is an object storage service offering 99.999999999% (11 9s) of durability.

- **Bucket**: Global unique container for objects (`s3://my-unique-bucket-name`).
- **Object**: File data plus key-value metadata (size up to 5TB per object).
