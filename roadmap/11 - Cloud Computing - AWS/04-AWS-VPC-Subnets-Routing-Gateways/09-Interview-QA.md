# 09 - Interview Q&A: AWS VPC

### Q: What is the key difference between Security Groups and Network ACLs?
**Answer:** Security Groups are stateful and applied at instance/ENI level with allow rules only. NACLs are stateless, applied at subnet level, and support both allow and deny rules evaluated in numerical order.
