# 04 - VPC Peering & AWS Transit Gateway

- **VPC Peering**: Direct 1-to-1 network connection between two VPCs (Non-transitive).
- **AWS Transit Gateway**: Centralized hub-and-spoke router connecting hundreds of VPCs and on-premises networks.
