# 02 - Internet Gateways & NAT Gateways

- **Internet Gateway (IGW)**: Enables 2-way internet traffic for instances in public subnets.
- **NAT Gateway**: Enables outbound internet connection for instances in private subnets while blocking inbound traffic from internet.
