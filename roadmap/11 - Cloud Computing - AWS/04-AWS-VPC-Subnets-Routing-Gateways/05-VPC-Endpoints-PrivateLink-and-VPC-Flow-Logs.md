# 05 - VPC Endpoints & VPC Flow Logs

- **Gateway Endpoints**: Free endpoints for S3 and DynamoDB via route table entry.
- **Interface Endpoints (PrivateLink)**: ENI-based endpoints for AWS services.
- **VPC Flow Logs**: Captures IP traffic flow metadata to CloudWatch Logs or S3.
