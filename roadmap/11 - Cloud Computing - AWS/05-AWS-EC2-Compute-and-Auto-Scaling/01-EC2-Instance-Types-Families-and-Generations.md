# 01 - EC2 Instance Types, Families & Generations

Naming convention: `t3a.xlarge`
- `t`: Family (General Purpose burstable)
- `3`: Generation
- `a`: AMD processor (`g` for ARM Graviton, `i` for Intel)
- `xlarge`: Size
