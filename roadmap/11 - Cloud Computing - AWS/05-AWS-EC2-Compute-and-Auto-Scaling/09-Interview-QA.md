# 09 - Interview Q&A: EC2 & Auto Scaling

### Q: When would you choose Network Load Balancer (NLB) over Application Load Balancer (ALB)?
**Answer:** Choose NLB for Layer 4 TCP/UDP performance, extreme low latency, handling millions of requests per second, or when static IP addresses per AZ are required.
