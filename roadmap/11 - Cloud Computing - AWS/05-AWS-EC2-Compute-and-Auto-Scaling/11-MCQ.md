# 11 - MCQ: EC2 Compute

#### Q1. What happens to data stored on an Instance Store volume when an EC2 instance is STOPPED?
- [x] A) Data is lost permanently
- [ ] B) Data is automatically backed up to S3
- [ ] C) Data is persisted until instance start
- [ ] D) Data is moved to EBS

<details><summary>Explanation</summary>Instance Store storage is ephemeral; stopping or terminating the underlying host instance permanently erases instance store data.</details>
