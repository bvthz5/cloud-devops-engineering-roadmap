# 05 - Elastic Load Balancers: ALB vs NLB

- **Application Load Balancer (ALB)**: Layer 7 HTTP/HTTPS content-based routing, path routing, host routing.
- **Network Load Balancer (NLB)**: Layer 4 TCP/UDP ultra-low latency load balancing with static IP addresses.
