# 01 - AWS Lambda Architecture

Lambda runs code in response to events and automatically manages compute resources.

- **Cold Start**: Initial initialization delay when a new execution environment is provisioned.
- **Provisioned Concurrency**: Keeps execution environments initialized for instant response.
