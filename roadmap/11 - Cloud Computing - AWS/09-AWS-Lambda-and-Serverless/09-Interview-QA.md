# 09 - Interview Q&A: AWS Lambda

### Q: How do you eliminate cold starts for latency-sensitive Lambda functions?
**Answer:** By configuring Provisioned Concurrency, which pre-warms execution environments to serve requests with sub-millisecond response times.
