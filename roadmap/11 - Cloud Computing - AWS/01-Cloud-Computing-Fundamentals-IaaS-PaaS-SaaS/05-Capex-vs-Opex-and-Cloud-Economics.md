# 05 - CapEx vs OpEx & Cloud Economics

- **Capital Expenditure (CapEx)**: Upfront capital spent on physical hardware, data center building, and power cooling.
- **Operational Expenditure (OpEx)**: Pay-as-you-go variable cost based on actual hourly or per-second resource usage.
