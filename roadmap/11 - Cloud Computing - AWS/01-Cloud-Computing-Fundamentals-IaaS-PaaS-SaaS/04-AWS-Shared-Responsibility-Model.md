# 04 - AWS Shared Responsibility Model

```text
+-------------------------------------------------------------+
|                  CUSTOMER RESPONSIBILITY                     |
|  - Customer Data & Encryption (In-Transit & At-Rest)        |
|  - IAM Access Management & Authentication Credentials        |
|  - Operating System Configuration & Patching (EC2)          |
|  - Network & Firewall Rules (Security Groups & NACLs)       |
+-------------------------------------------------------------+
===============================================================
+-------------------------------------------------------------+
|                     AWS RESPONSIBILITY                      |
|  - Physical Security of Data Centers                        |
|  - Server Hardware, Host Virtualization & Hypervisor        |
|  - Global Infrastructure (Regions, AZs, Edge Locations)     |
|  - Core Networking Infrastructure                           |
+-------------------------------------------------------------+
```
