# 01 - AWS IAM Architecture & Identity Management

IAM controls **who** (authentication) can do **what** (authorization) on **which** AWS resources.

```text
[Principal (User/Role)] ──> [AWS API Request] ──> [IAM Evaluation Engine] ──> Allow / Deny
```
