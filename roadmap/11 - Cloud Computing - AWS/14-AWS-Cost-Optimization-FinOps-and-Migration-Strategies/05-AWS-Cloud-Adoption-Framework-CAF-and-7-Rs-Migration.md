# 05 - AWS CAF & The 7 Rs Migration Strategies

```text
 1. Rehost (Lift and Shift)    ──> Move VMs directly to EC2 without changes
 2. Replatform (Lift and Reshape) ──> Move database to RDS/Aurora
 3. Refactor (Re-architect)    ──> Modernize to Cloud-Native / Serverless
 4. Repurchase (Drop and Shop) ──> Switch to SaaS solution
 5. Relocate                   ──> Move VMware workloads to AWS
 6. Retain                     ──> Keep applications on-premises
 7. Retire                     ──> Decommission unneeded applications
```
