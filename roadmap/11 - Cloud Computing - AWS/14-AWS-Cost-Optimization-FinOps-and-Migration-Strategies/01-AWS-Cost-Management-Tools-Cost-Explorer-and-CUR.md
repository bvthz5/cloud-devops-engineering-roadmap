# 01 - AWS Cost Management Tools

- **AWS Cost Explorer**: Visualize, analyze, and forecast AWS spending over time.
- **AWS Cost & Usage Reports (CUR)**: Detailed raw billing data delivered to S3.
- **AWS Budgets**: Set custom spending limits and trigger alerts via email/SNS.
