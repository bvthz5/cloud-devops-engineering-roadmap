# 03 - AWS CloudTrail: Governance & API Auditing

CloudTrail records API calls made by users, roles, or AWS services (**Who did What, When, and from Where**).

- **Management Events**: Control plane operations (e.g. `CreateBucket`, `RunInstances`).
- **Data Events**: Resource-level operations (e.g. `s3:GetObject`, `lambda:Invoke`).
