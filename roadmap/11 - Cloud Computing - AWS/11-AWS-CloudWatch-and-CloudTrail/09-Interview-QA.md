# 09 - Interview Q&A: Observability & Auditing

### Q: What is the primary difference between CloudWatch and CloudTrail?
**Answer:** CloudWatch monitors system performance metrics, logs, and application health. CloudTrail records API audit logs tracking user activity and API calls across the AWS account.
