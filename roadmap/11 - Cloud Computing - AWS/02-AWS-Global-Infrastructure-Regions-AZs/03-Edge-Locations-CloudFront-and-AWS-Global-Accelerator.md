# 03 - Edge Locations, CloudFront & Global Accelerator

- **Edge Locations (Points of Presence - PoPs)**: Cache content close to end users via CloudFront CDN.
- **AWS Global Accelerator**: Routes user traffic over AWS global private network backbone using static Anycast IPs.
