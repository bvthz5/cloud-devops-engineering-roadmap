# 09 - Interview Q&A: AWS Global Infrastructure

### Q: Why do different AWS accounts see different physical data centers for `us-east-1a`?
**Answer:** AWS randomly maps logical AZ names (`us-east-1a`) to physical AZ IDs (`use1-az1`) per account to distribute resource utilization evenly.
