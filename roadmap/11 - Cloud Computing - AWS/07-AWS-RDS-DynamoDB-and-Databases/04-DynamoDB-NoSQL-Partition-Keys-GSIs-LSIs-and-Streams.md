# 04 - Amazon DynamoDB NoSQL

Serverless key-value and document database delivering single-digit millisecond latency at any scale.

- **Partition Key (Hash Key)**: Distributes data across internal partitions.
- **Sort Key (Range Key)**: Sorts items within the same partition.
- **Global Secondary Index (GSI)**: Secondary index spanning all table partitions.
