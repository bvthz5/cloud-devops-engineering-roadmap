# 09 - Interview Q&A: AWS Databases

### Q: What is the difference between RDS Multi-AZ and RDS Read Replicas?
**Answer:** Multi-AZ provides synchronous replication to a passive standby for automatic failover and high availability. Read Replicas use asynchronous replication to active secondary instances to scale read query capacity.
