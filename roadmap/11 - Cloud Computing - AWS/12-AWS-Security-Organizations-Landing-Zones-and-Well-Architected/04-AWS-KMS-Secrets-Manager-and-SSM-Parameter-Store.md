# 04 - AWS KMS, Secrets Manager & SSM Parameter Store

- **AWS KMS**: Managed encryption keys (KMS CMKs).
- **Secrets Manager**: Encrypted secrets with automated credential rotation (DB passwords).
- **SSM Parameter Store**: Key-value storage for configuration data and parameters.
