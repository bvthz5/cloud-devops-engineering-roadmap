# 06 - AWS Well-Architected Framework (6 Pillars)

1. **Operational Excellence**: Automate operations and learn from failures.
2. **Security**: Protect data, systems, and assets via Defense-in-Depth.
3. **Reliability**: Recover automatically from failure and scale horizontally.
4. **Performance Efficiency**: Use right-sized compute and serverless architectures.
5. **Cost Optimization**: Eliminate unneeded resource waste.
6. **Sustainability**: Minimize environmental impact of cloud workloads.
