# 05 - AWS Security Services: GuardDuty, Security Hub & WAF

- **GuardDuty**: Intelligent threat detection using machine learning on CloudTrail, VPC Flow Logs, and DNS logs.
- **Security Hub**: Centralized security posture management and CIS compliance scoring.
- **AWS WAF**: Web Application Firewall protecting against SQL injection, XSS, and layer 7 exploits.
- **AWS Shield**: Managed DDoS protection (Standard & Advanced).
