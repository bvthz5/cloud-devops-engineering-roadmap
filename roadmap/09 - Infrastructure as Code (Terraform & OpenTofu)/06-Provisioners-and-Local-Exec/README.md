# 06 - Provisioners & Local-Exec

> **Learning Methodology:**
> **Understand -> See -> Practice -> Troubleshoot -> Interview -> Revise**

## Module Syllabus
1. `01-Provisioner-Types-local-exec-remote-exec-file.md` - The three built-in provisioners, their use cases, and when (not) to use them.
2. `02-Connection-Blocks-SSH-and-WinRM.md` - Configuring SSH and WinRM connections for remote-exec and file provisioners.
3. `03-Null-Resource-and-Triggers.md` - Using null_resource with triggers for arbitrary scripting, and the terraform_data replacement.
4. `04-User-Data-and-Cloud-Init-vs-Provisioners.md` - Cloud-native alternatives: user_data scripts, cloud-init, and why they are preferred over provisioners.
5. `05-Packer-Image-Baking-vs-Runtime-Provisioning.md` - Build-time (Packer) vs run-time (provisioner) configuration, and the immutable infrastructure approach.
6. `06-External-Data-Source-and-Custom-Scripts.md` - The external data source for calling scripts that return JSON, and integration with Ansible/Chef.
7. `07-Real-World-Scenarios.md` - Production patterns and anti-patterns with provisioners.
8. `08-Troubleshooting.md` - Provisioner failure diagnostics.
9. `09-Interview-QA.md` - Interview questions on provisioners.
10. `10-Hands-On-Practice.md` - Labs with provisioners and cloud-init.
11. `11-MCQ.md` - MCQs on provisioners.
12. `12-Quick-Revision.md` - Provisioner cheat sheet.
