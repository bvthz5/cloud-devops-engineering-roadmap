# 07 - Terraform Workspaces & Environment Segregation

> **Learning Methodology:**
> **Understand -> See -> Practice -> Troubleshoot -> Interview -> Revise**

## Module Syllabus
1. `01-Terraform-Workspaces-Architecture-and-CLI.md` - Workspace internals, CLI commands, and state isolation per workspace.
2. `02-Workspaces-vs-Directory-Based-Environments.md` - Comparing workspace-based vs directory/folder-based environment strategies.
3. `03-Environment-Segregation-Patterns.md` - Per-account, per-workspace, per-directory, and hybrid patterns for dev/staging/prod.
4. `04-Variable-Files-and-tfvars-per-Environment.md` - Using .tfvars files, -var-file flag, and environment-specific variable management.
5. `05-Terraform-Cloud-Workspaces-and-VCS-Workflows.md` - HCP Terraform (Terraform Cloud) workspaces, VCS-driven runs, and run triggers.
6. `06-Multi-Account-Multi-Region-Deployment.md` - Provider aliases, assume_role, and deploying across AWS accounts/GCP projects/Azure subscriptions.
7. `07-Real-World-Scenarios.md` - Environment strategy failures and successes.
8. `08-Troubleshooting.md` - Workspace and environment error diagnostics.
9. `09-Interview-QA.md` - Interview questions on environment management.
10. `10-Hands-On-Practice.md` - Labs with workspaces and multi-environment deploys.
11. `11-MCQ.md` - MCQs on workspaces.
12. `12-Quick-Revision.md` - Environment strategy cheat sheet.
