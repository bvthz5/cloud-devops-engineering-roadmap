# 12 - Terraform Provider Development

> **Learning Methodology:**
> **Understand -> See -> Practice -> Troubleshoot -> Interview -> Revise**

## Module Syllabus
1. `01-Provider-Plugin-Framework-and-SDK.md` - Terraform Plugin Framework vs legacy SDK v2, gRPC protocol.

3. `03-Resource-and-Data-Source-Implementation.md` - Implementing Create, Read, Update, Delete and data sources.
4. `04-Testing-and-Publishing-Providers.md` - Acceptance tests, unit tests, and publishing to the Terraform Registry.
5. `05-Provider-Design-Patterns.md` - Error handling, retry logic, pagination, and API client patterns.
6. `06-Community-Providers-and-Contribution.md` - Contributing to existing providers, forking, and community governance.
7. `07-Real-World-Scenarios.md` - Building providers for internal APIs.
8. `08-Troubleshooting.md` - Provider development debugging.
9. `09-Interview-QA.md` - Interview questions on providers.
10. `10-Hands-On-Practice.md` - Lab: Build a simple custom provider.
11. `11-MCQ.md` - MCQs on provider development.
12. `12-Quick-Revision.md` - Provider development cheat sheet.
