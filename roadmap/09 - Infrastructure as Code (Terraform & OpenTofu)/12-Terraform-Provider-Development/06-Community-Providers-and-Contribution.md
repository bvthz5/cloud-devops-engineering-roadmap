# 06 - Community Providers & Contribution

## 1. Contributing to Existing Providers

1. Fork the provider repository
2. Set up development environment (Go, Terraform)
3. Create a feature branch
4. Implement changes with acceptance tests
5. Submit PR with documentation updates

## 2. Popular Community Providers

| Provider | Use Case |
|---|---|
| `grafana/grafana` | Grafana dashboards and alerts |
| `datadog/datadog` | Datadog monitors and dashboards |
| `cloudflare/cloudflare` | DNS, WAF, Workers |
| `mongodb/mongodbatlas` | MongoDB Atlas clusters |
| `snowflake-labs/snowflake` | Snowflake databases |
