# 08 - Troubleshooting

| Issue | Fix |
|---|---|
| Import shows "resource already in state" | Resource was already imported |
| Plan shows changes after import | Align HCL to match actual resource attributes |
| moved block causes recreation | Verify from/to addresses match exactly |
| generate-config includes computed attrs | Remove read-only attributes from generated HCL |
