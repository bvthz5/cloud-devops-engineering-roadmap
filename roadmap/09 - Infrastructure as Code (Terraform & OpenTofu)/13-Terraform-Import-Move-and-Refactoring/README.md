# 13 - Terraform Import, Move & Refactoring

> **Learning Methodology:**
> **Understand -> See -> Practice -> Troubleshoot -> Interview -> Revise**

## Module Syllabus
1. `01-terraform-import-CLI-and-Import-Block.md` - Importing existing resources into state using CLI and declarative import blocks.
2. `02-moved-Block-Refactoring.md` - Renaming resources, moving into modules, and refactoring without destroy/recreate.
3. `03-removed-Block-and-State-Surgery.md` - The removed block (>= 1.7), terraform state rm, and safe state manipulation.
4. `04-Generate-Config-from-Import.md` - Using terraform plan -generate-config-out to auto-generate HCL from imported resources.
5. `05-Large-Scale-Migration-Strategies.md` - Migrating hundreds of existing resources into Terraform management.
6. `06-Refactoring-Patterns-and-Best-Practices.md` - Module extraction, resource renaming, state splitting patterns.
7. `07-Real-World-Scenarios.md` - Migration case studies.
8. `08-Troubleshooting.md` - Import and move error diagnostics.
9. `09-Interview-QA.md` - Interview questions on refactoring.
10. `10-Hands-On-Practice.md` - Labs with import and moved blocks.
11. `11-MCQ.md` - MCQs on import/refactoring.
12. `12-Quick-Revision.md` - Import/refactoring cheat sheet.
