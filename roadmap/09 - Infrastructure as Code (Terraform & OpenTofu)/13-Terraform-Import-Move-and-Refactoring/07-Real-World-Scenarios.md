# 07 - Real-World Scenarios

## Scenario: Migrating 500 AWS Resources to Terraform

A company had 500 AWS resources created via ClickOps. Used `terraformer` to generate initial HCL, followed by `terraform import` for each resource, then organized into modules with `moved` blocks. Total migration time: 3 weeks.
