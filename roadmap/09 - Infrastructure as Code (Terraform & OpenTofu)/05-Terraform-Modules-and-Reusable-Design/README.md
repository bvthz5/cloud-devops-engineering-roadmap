# 05 - Terraform Modules & Reusable Design

> **Learning Methodology:**
> **Understand → See → Practice → Troubleshoot → Interview → Revise**

## 📌 Module Syllabus
1. `01-Module-Architecture-Root-vs-Child-Modules.md` — Root modules, child modules, module registry, local modules, and the module call lifecycle.
2. `02-Module-Inputs-Outputs-and-Composition.md` — Passing variables into modules, exposing outputs, module composition, and dependency chains.
3. `03-Module-Sources-Registry-Git-S3-and-Local.md` — Module sourcing: Terraform Registry, Git repositories, S3 buckets, GCS, and local paths with version pinning.
4. `04-Module-Design-Patterns-and-Best-Practices.md` — Thin wrapper modules, opinionated modules, composable modules, anti-patterns, and naming conventions.
5. `05-Publishing-Modules-to-Terraform-Registry.md` — Registry requirements, module structure, semantic versioning, documentation, and automated publishing.
6. `06-Module-Testing-with-Terratest-and-terraform-test.md` — Unit testing with `terraform test` (native), integration testing with Terratest (Go), and contract testing.
7. `07-Real-World-Scenarios.md` — Enterprise module library design, module versioning failures, and multi-cloud module abstraction.
8. `08-Troubleshooting.md` — Module errors and resolution runbooks.
9. `09-Interview-QA.md` — Interview questions on module architecture.
10. `10-Hands-On-Practice.md` — Labs: Create, publish, and consume reusable modules.
11. `11-MCQ.md` — Scenario-based MCQs on modules.
12. `12-Quick-Revision.md` — Module design cheat sheet.
