# 01 - IaC Concepts & Evolution

> **Learning Methodology:**
> **Understand → See → Practice → Troubleshoot → Interview → Revise**

## 📌 Module Syllabus
1. `01-What-Is-IaC-Declarative-vs-Imperative.md` — Defining Infrastructure as Code, declarative vs imperative paradigms, idempotency, and the shift from manual provisioning to code-driven automation.
2. `02-IaC-Tooling-Landscape-Terraform-Pulumi-CloudFormation.md` — Comparison of Terraform/OpenTofu, Pulumi, AWS CloudFormation, Azure Bicep, Google Deployment Manager, and Crossplane.
3. `03-Mutable-vs-Immutable-Infrastructure.md` — Snowflake servers vs phoenix servers, configuration drift, the golden image pattern, and immutable infrastructure with Packer.
4. `04-IaC-Workflow-Write-Plan-Apply.md` — The universal IaC lifecycle: write, validate, plan, apply, and destroy; version-controlling infrastructure.
5. `05-IaC-in-the-SDLC-and-DevOps-Pipeline.md` — Embedding IaC in CI/CD, peer review of infrastructure changes, blast radius control, and progressive rollouts.
6. `06-OpenTofu-The-Open-Source-Fork.md` — History of the HashiCorp BSL license change, Linux Foundation stewardship, OpenTofu compatibility, feature parity, and migration path from Terraform.
7. `07-Real-World-Scenarios.md` — Production war stories: drift disasters, manual console changes vs IaC, and multi-team IaC adoption failures.
8. `08-Troubleshooting.md` — Common IaC adoption pitfalls and how to diagnose them.
9. `09-Interview-QA.md` — Senior DevOps/SRE interview questions on IaC fundamentals.
10. `10-Hands-On-Practice.md` — Lab: Bootstrap a local Terraform/OpenTofu project from scratch.
11. `11-MCQ.md` — Scenario-based multiple-choice questions on IaC concepts.
12. `12-Quick-Revision.md` — High-density IaC concepts cheat sheet.
