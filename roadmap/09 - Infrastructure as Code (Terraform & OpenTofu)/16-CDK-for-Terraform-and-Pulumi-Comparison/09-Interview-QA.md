# 09 - Interview Questions

### Q1: When would you choose CDKTF or Pulumi over HCL Terraform?
**Answer:** When the team is already proficient in TypeScript/Python/Go and wants full programming language features (loops, classes, error handling, standard testing). CDKTF is ideal when you want to keep Terraform's state management and provider ecosystem but use a familiar language.
