# 10 - IaC Security, tfsec & Checkov

> **Learning Methodology:**
> **Understand -> See -> Practice -> Troubleshoot -> Interview -> Revise**

## Module Syllabus
1. `01-IaC-Security-Threat-Model-and-Attack-Surface.md` - Security risks in IaC: exposed secrets, overly permissive policies, state file leaks.
2. `02-tfsec-Static-Security-Scanner.md` - Running tfsec for security scanning, custom rules, and CI integration.
3. `03-Checkov-Policy-as-Code-Scanner.md` - Checkov for compliance scanning, built-in policies, and custom checks.
4. `04-Secret-Management-Vault-AWS-SSM-SOPS.md` - Integrating HashiCorp Vault, AWS SSM Parameter Store, SOPS, and external secret managers.
5. `05-Least-Privilege-IAM-for-Terraform.md` - Designing minimal IAM policies for Terraform execution roles.
6. `06-Supply-Chain-Security-Provider-Signing-and-Lock-Files.md` - Provider signing, GPG verification, lock file integrity, and private registries.
7. `07-Real-World-Scenarios.md` - Security incidents involving IaC.
8. `08-Troubleshooting.md` - Security tool errors and fixes.
9. `09-Interview-QA.md` - Interview questions on IaC security.
10. `10-Hands-On-Practice.md` - Labs with tfsec, Checkov, and Vault.
11. `11-MCQ.md` - MCQs on IaC security.
12. `12-Quick-Revision.md` - IaC security cheat sheet.
