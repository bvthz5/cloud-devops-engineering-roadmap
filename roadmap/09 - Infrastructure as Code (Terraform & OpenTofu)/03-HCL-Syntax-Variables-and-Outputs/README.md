# 03 - HCL Syntax, Variables & Outputs

> **Learning Methodology:**
> **Understand → See → Practice → Troubleshoot → Interview → Revise**

## 📌 Module Syllabus
1. `01-HCL-Language-Fundamentals-Blocks-Arguments-Expressions.md` — Block types, arguments, expressions, comments, and the HCL specification.
2. `02-Variables-Types-Validation-and-Precedence.md` — Input variables, type system (string, number, bool, list, map, object, tuple), validation rules, and variable precedence order.
3. `03-Outputs-Data-Sources-and-Cross-Module-References.md` — Output values, data sources, terraform_remote_state, and passing data between modules.
4. `04-Locals-Expressions-and-Built-in-Functions.md` — Local values, conditional expressions, string interpolation, and Terraform's 100+ built-in functions.
5. `05-Dynamic-Blocks-for_each-count-and-Iteration.md` — Dynamic blocks, for_each vs count, for expressions, splat operators, and conditional resource creation.
6. `06-Type-Constraints-Complex-Types-and-any.md` — Complex types (object, tuple, set), `any` type, optional attributes, nullable variables, and type conversion.
7. `07-Real-World-Scenarios.md` — Production patterns: dynamic security group rules, conditional resource creation, multi-region with for_each.
8. `08-Troubleshooting.md` — Common HCL errors and how to fix them.
9. `09-Interview-QA.md` — Interview questions on HCL, variables, and functions.
10. `10-Hands-On-Practice.md` — Labs: Complex variable types, dynamic blocks, and function usage.
11. `11-MCQ.md` — Scenario-based MCQs on HCL syntax.
12. `12-Quick-Revision.md` — HCL syntax and functions cheat sheet.
