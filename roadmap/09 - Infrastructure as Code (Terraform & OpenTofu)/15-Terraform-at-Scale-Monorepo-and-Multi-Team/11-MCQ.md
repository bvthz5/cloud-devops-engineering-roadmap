# 11 - MCQ

### Question 1
What is the "producer-consumer" model in multi-team Terraform?
- [x] A) Platform team builds modules (producers), application teams use them (consumers)
- [ ] B) One team plans, another team applies
- [ ] C) Producers write Terraform, consumers write Pulumi
- [ ] D) A CI/CD pattern for parallel deployments

<details>
<summary>Explanation</summary>
The producer-consumer model separates module creation (platform/infra team) from module consumption (application teams). This enforces standards while giving teams self-service access.
</details>
