# 08 - Troubleshooting

| Issue | Fix |
|---|---|
| Plan too slow | Split state, reduce parallelism |
| Teams blocked by state locks | Separate states per team/domain |
| Module version conflicts | Enforce version pinning policies |
| Too many PRs to review | Automate with Atlantis/TFC auto-apply for non-prod |
