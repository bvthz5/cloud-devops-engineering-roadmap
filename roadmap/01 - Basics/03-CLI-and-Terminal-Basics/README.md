# 03-CLI and Terminal Basics

> Terminal vs Terminal Emulator vs Shell, command anatomy, paths, environment variables, exit codes, standard streams, redirection, pipes, wildcards, quoting, aliases, and essential DevOps CLI practices.

---

## 🎯 Learning Objectives

By the end of this module, you will understand:
1. **CLI Distinctions:** Terminal vs Terminal Emulator vs Shell vs Executable Command.
2. **Command Structure:** Command name, options/flags (`-a`, `--all`), arguments, and options processing.
3. **Path Navigation:** Absolute paths (`/etc/nginx`), relative paths (`./app`), `.`, `..`, and `~`.
4. **Command Execution Mechanics:** `PATH` variable, executable lookup, `which`, `type`, `whereis`, and exit status codes ($?).
5. **Streams & I/O Manipulation:** `stdin` (0), `stdout` (1), `stderr` (2), redirection (`>`, `>>`, `<`, `2>&1`), and piping (`|`).
6. **Shell Grammar & Expansion:** Wildcards (`*`, `?`), quoting (single vs double), command substitution (`$()`), environment variables, aliases, and manual pages.
