### Q1. What is the average time complexity of looking up a key in a Hash Table?
- [ ] A) $O(N)$
- [ ] B) $O(1)$
- [ ] C) $O(\log N)$
- [ ] D) $O(N^2)$

<details>
<summary><b>View Answer</b></summary>
<b>Correct Answer: B</b><br>
A hash table computes the bucket index directly from the hash function, yielding average $O(1)$ constant time lookup.
</details>
