# 11 — Multiple Choice Questions: Binary & Encoding

### Q1. What is the Base64 encoding size overhead compared to raw binary data?
- [ ] A) Exactly 50%
- [ ] B) Approximately 33% (4 output bytes for every 3 input bytes)
- [ ] C) 0% (same size)
- [ ] D) 100% (doubles the size)

<details>
<summary><b>View Answer</b></summary>
<b>Correct Answer: B</b><br>
Base64 transforms 3 bytes (24 bits) into 4 characters (6 bits each), resulting in a ~33% increase in data volume.
</details>
