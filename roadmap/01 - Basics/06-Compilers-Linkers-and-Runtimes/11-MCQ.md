### Q1. Which command displays the shared libraries required by an executable on Linux?
- [ ] A) `lsmod`
- [ ] B) `ldd`
- [ ] C) `readlink`
- [ ] D) `ps -ef`

<details>
<summary><b>View Answer</b></summary>
<b>Correct Answer: B</b><br>
<code>ldd</code> prints the shared objects (libraries) required by each program or shared library specified on the command line.
</details>
