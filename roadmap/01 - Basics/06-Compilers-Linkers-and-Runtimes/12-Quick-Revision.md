# 12 — Quick Revision Cheat Sheet: Compilers & Runtimes

---

## 1. Key Commands

```bash
ldd /path/to/binary           # Show dynamic library dependencies
file /path/to/binary          # Check architecture and static/dynamic linking
readelf -h /path/to/binary    # Inspect ELF headers
CGO_ENABLED=0 go build        # Build static Go binary
```
