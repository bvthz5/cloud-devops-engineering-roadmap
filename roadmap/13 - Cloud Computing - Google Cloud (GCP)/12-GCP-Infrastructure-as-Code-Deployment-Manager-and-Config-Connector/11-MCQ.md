### Question 1
Which GCP security feature prevents data exfiltration by establishing virtual perimeters around sensitive Google API services?
- [ ] A) Cloud Armor
- [x] B) VPC Service Controls
- [ ] C) IAM Custom Roles
- [ ] D) Security Command Center

*Explanation: VPC Service Controls define security perimeters around GCP APIs to prevent data exfiltration.*

### Question 2
What is the primary benefit of Anthos Config Management (ACM)?
- [ ] A) Automatically optimizes GCP billing costs
- [x] B) Synchronizes Kubernetes policies and configurations from Git across multi-cluster hybrid fleets
- [ ] C) Replaces the need for Cloud Load Balancing
- [ ] D) Converts ARM templates into Kubernetes manifests

*Explanation: ACM enables GitOps management for multi-cluster environments across GCP, AWS, and on-premises.*

### Question 3
How do Committed Use Discounts (CUDs) provide cost savings in GCP?
- [ ] A) By automatically shutting down idle VMs at night
- [x] B) By offering discounted rates in exchange for a 1-year or 3-year usage commitment
- [ ] C) By converting block storage into object storage
- [ ] D) By routing network traffic over public internet peering

*Explanation: CUDs offer deeply discounted rates for committed compute and database usage over 1 to 3 years.*
