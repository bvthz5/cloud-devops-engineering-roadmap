### Q1. Which Linux utility prevents concurrent runs of a cron job by acquiring an exclusive file lock?
- A) `lockfile`
- B) `flock`
- C) `mutex`
- D) `sem_wait`
<details><summary><b>View Answer</b></summary><b>Correct Answer: B</b><br>`flock` is the standard Linux kernel file-locking command.</details>
