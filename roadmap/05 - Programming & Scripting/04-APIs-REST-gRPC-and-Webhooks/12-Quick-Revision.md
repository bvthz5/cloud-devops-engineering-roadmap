# 12 - APIs & Webhooks: Quick Revision Cheat Sheet

## HTTP Status Codes Summary
- `200 OK`: Request succeeded.
- `201 Created`: Resource successfully created (`POST`).
- `204 No Content`: Action succeeded, zero payload returned (`DELETE`).
- `400 Bad Request`: Client sent malformed payload.
- `401 Unauthorized`: Missing or invalid credentials.
- `403 Forbidden`: Authenticated, but lacking permission.
- `429 Too Many Requests`: Rate limit exceeded.
- `502 Bad Gateway`: Upstream service unreachable or crashed.
- `503 Service Unavailable`: Target overloaded or in maintenance.
