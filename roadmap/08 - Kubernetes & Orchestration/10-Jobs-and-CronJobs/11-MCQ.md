# 11 - Multiple-Choice Assessment (MCQ)

### Question 1
Which concurrency policy skips a new job execution if the previously scheduled job is still running?
- [ ] A) Allow
- [x] B) Forbid
- [ ] C) Replace
- [ ] D) Block

<details>
<summary>Explanation</summary>
`concurrencyPolicy: Forbid` ensures that no overlapping instances of the job run simultaneously.
</details>
