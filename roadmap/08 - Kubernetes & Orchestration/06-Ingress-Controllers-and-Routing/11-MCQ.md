# 11 - Multiple-Choice Assessment (MCQ)

### Question 1
Which `pathType` matches the path prefix based on URL path segments separated by `/`?
- [ ] A) Exact
- [x] B) Prefix
- [ ] C) ImplementationSpecific
- [ ] D) Wildcard

<details>
<summary>Explanation</summary>
`pathType: Prefix` matches URL path elements split by `/`. For example, `/foo` matches `/foo` and `/foo/bar`, but not `/foobar`.
</details>
