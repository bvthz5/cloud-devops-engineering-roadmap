# 11 - Multiple-Choice Assessment (MCQ)

### Question 1
Which flag allows `kubectl` to output specific object fields in a format optimal for bash scripts?
- [ ] A) `-o wide`
- [x] B) `-o jsonpath='{...}'`
- [ ] C) `--dry-run=client`
- [ ] D) `-o yaml`

<details>
<summary>Explanation</summary>
`-o jsonpath` extracts exact values directly from the JSON representation without requiring external parsers like `jq`.
</details>
