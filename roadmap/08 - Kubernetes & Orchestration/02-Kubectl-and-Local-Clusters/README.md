# 02 - Kubectl and Local Clusters

> **Learning Methodology:**
> **Understand → See → Practice → Troubleshoot → Interview → Revise**

## 📌 Module Syllabus
1. `01-Kubectl-Architecture-Kubeconfig-and-Contexts.md` — The anatomy of `~/.kube/config`, cluster endpoints, users, contexts, and authentication tokens.
2. `02-Essential-Kubectl-Commands-and-Output-Formatting.md` — CRUD operations, JSONPath, custom-columns, sorting, and imperative vs declarative management.
3. `03-Kubectl-Plugins-and-Krew-Ecosystem.md` — Extending kubectl with Krew: `ctx`, `ns`, `who-can`, `neat`, and custom shell plugins.
4. `04-Local-Cluster-Setup-with-Kind-and-Minikube.md` — Kubernetes-in-Docker (Kind), multi-node cluster topology manifests, and Minikube driver configs.
5. `05-Lightweight-Edge-Kubernetes-with-K3s-and-MicroK8s.md` — Single-binary distributions, SQLite/etcd replacements, and IoT/edge resource constraints.
6. `06-Production-Bootstrap-with-Kubeadm.md` — Production cluster initialization: `kubeadm init`, join tokens, CNI installation, and master node taints.
7. `07-Real-World-Scenarios.md` — Production post-mortems: context mixup disasters, credential expirations, and Kind node port forwarding loops.
8. `08-Troubleshooting.md` — Diagnostic decision trees for broken kubeconfigs and local cluster bootstrap failures.
9. `09-Interview-QA.md` — 10 Senior SRE/DevOps interview scenarios on kubectl and local environments.
10. `10-Hands-On-Practice.md` — Multi-node Kind cluster provisioning with custom node labels and port mapping.
11. `11-MCQ.md` — 10 scenario-based multiple choice questions with detailed explanations.
12. `12-Quick-Revision.md` — High-density kubectl command reference and alias cheatsheet.
