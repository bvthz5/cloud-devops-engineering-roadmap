# 11 - Multiple-Choice Assessment (MCQ)

### Question 1
In the Kubernetes Gateway API, which persona typically creates and manages `HTTPRoute` resources?
- [ ] A) Cloud Infrastructure Provider
- [ ] B) Cluster Security Administrator
- [x] C) Application Developer
- [ ] D) Storage Administrator

<details>
<summary>Explanation</summary>
Gateway API is role-oriented: Infrastructure Providers manage `GatewayClass`, Cluster Operators manage `Gateway`, and Application Developers manage Routes (`HTTPRoute`, `GRPCRoute`).
</details>
