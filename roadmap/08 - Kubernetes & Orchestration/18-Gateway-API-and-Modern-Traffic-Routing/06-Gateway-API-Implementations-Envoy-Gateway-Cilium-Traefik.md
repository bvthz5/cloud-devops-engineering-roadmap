# 06 - Gateway API Implementations: Envoy Gateway, Cilium, and Traefik

## 1. Leading Implementations

- **Envoy Gateway:** The official CNCF reference implementation built on Envoy Proxy.
- **Cilium Gateway API:** Leverages eBPF for Layer 4 load balancing and Envoy for Layer 7 routing.
- **Istio Gateway API:** Implements Gateway API as the standard replacement for Istio `VirtualService` and `Gateway` CRDs.
