# 04 - Agent Pools: Microsoft-Hosted vs Self-Hosted

- **Microsoft-Hosted**: Maintenance-free, fresh VM instance per job.
- **Self-Hosted**: Virtual machines/containers inside private VNet with custom software pre-installed.
