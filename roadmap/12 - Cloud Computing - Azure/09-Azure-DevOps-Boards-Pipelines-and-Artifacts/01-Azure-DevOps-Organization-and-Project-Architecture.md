# 01 - Azure DevOps Organization Architecture

```text
Azure DevOps Organization
 └── Projects (Agile / Scrum / Basic)
      ├── Boards     (Work items & Sprints)
      ├── Repos      (Git Repositories)
      ├── Pipelines  (Build & Release YAML Pipelines)
      ├── Test Plans (Manual & Automated Testing)
      └── Artifacts  (Package Feeds)
```
