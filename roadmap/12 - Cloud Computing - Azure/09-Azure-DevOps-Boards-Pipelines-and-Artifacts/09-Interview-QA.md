# 09 - Interview Q&A: Azure DevOps

### Q: How do Service Connections authenticate to Azure securely without client secrets?
**Answer:** Using Workload Identity federation, which establishes a trust relationship between Azure DevOps pipelines and Microsoft Entra ID.
