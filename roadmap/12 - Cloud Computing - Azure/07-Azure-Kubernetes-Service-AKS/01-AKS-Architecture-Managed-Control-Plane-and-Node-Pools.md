# 01 - AKS Architecture: Control Plane & Node Pools

- **Control Plane**: Managed by Azure (API server, etcd, controller manager).
- **System Node Pool**: Hosts critical system pods (CoreDNS, metrics-server).
- **User Node Pool**: Hosts customer application workloads.
