# 09 - Interview Q&A: Azure AKS

### Q: What is the main advantage of Entra Workload Identity over pod-identity in AKS?
**Answer:** Workload Identity uses standard OpenID Connect (OIDC) federation, eliminating the need for NMI/MIC controller daemons and scaling better without node-level performance bottlenecks.
