# 01 - Infrastructure as Code on Azure: ARM vs Bicep

Bicep is a domain-specific language (DSL) for deploying Azure resources declaratively, transpiling directly to ARM JSON templates.

```text
 [Bicep Code (.bicep)] ──(Transpiles)──> [ARM JSON Template] ──> [ARM Engine API]
```
