# 09 - Interview Q&A: Azure Bicep

### Q: How does Bicep differ from Terraform for Azure infrastructure provisioning?
**Answer:** Bicep is an Azure-native DSL created by Microsoft that offers immediate day-0 support for all Azure resource provider APIs with zero state file management requirement. Terraform is multi-cloud and manages state via state files.
