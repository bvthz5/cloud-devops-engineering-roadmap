# 04 - Azure Global Infrastructure

- **Regions**: 60+ datacenter regions worldwide.
- **Paired Regions**: Regional pair in same geography for disaster recovery (e.g. East US <-> West US).
- **Availability Zones**: Physically separate datacenters within a region.
