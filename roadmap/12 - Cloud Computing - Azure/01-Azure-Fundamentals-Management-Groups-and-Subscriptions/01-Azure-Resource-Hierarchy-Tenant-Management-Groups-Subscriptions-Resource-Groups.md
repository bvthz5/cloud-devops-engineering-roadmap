# 01 - Azure Resource Hierarchy

```text
Entra ID Tenant (Root Management Group)
 └── Management Groups (e.g. Production / Non-Production)
      └── Subscriptions (e.g. Pay-As-You-Go / Enterprise)
           └── Resource Groups (e.g. rg-web-prod-eastus)
                └── Resources (VMs, VNets, Storage Accounts)
```
