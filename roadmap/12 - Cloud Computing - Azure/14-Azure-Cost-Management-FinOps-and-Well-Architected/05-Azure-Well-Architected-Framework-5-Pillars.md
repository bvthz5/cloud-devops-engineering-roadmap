# 05 - Azure Well-Architected Framework (5 Pillars)

1. **Reliability**: Ability of system to recover from failures and function continuously.
2. **Security**: Protecting data and applications from threats.
3. **Cost Optimization**: Managing costs to maximize value delivered.
4. **Operational Excellence**: Operations processes that keep system running in production.
5. **Performance Efficiency**: Ability of workload to scale to meet demands efficiently.
