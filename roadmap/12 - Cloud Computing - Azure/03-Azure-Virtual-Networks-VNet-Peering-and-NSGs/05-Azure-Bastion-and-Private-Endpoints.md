# 05 - Azure Bastion & Private Endpoints

- **Azure Bastion**: Fully managed PaaS proxy providing seamless RDP/SSH access over TLS (Port 443) via browser.
- **Private Endpoint**: Private IP network interface connecting securely to Azure PaaS services (Blob, SQL).
