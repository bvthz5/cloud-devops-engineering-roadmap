# 02 - Network Security Groups (NSGs) & ASGs

NSGs filter network traffic using 5-tuple rules (Source, Source Port, Destination, Destination Port, Protocol).

- Priority evaluated from **100 to 4096** (Lower numerical value = Higher priority).
- **Stateful**: Return traffic automatically allowed.
