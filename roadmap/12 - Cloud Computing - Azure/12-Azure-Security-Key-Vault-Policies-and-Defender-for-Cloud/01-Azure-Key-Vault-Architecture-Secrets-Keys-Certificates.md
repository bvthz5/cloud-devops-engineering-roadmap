# 01 - Azure Key Vault Architecture

Key Vault safeguards cryptographic keys, database passwords, and TLS certificates in Hardware Security Modules (HSMs).

- **Soft Delete**: Retains deleted vaults/secrets for specified retention period (7-90 days).
- **Purge Protection**: Prevents permanent deletion of soft-deleted vaults prior to retention expiry.
