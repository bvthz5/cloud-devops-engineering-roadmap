# 02 - Key Vault Access Policies vs Azure RBAC

- **Vault Access Policies**: Legacy authorization model granting permission per secret category.
- **Azure RBAC Authorization** (Recommended): Fine-grained access control using Entra ID roles (e.g. `Key Vault Secrets User`).
