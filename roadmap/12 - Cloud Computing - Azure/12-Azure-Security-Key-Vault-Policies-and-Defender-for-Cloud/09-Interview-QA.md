# 09 - Interview Q&A: Azure Security

### Q: What is an Azure Policy Initiative?
**Answer:** An Initiative (also known as a policy set) is a group of related Azure Policy definitions packaged together to achieve a single compliance goal (e.g. CIS Azure Benchmark).
