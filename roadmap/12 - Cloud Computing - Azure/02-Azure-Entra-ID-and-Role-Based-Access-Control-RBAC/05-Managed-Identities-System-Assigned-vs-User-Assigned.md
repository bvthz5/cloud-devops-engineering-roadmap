# 05 - Managed Identities: System-Assigned vs User-Assigned

- **System-Assigned**: Tied directly to a single resource (e.g. VM). Lifecycle linked to resource.
- **User-Assigned**: Standalone Azure resource that can be assigned to multiple VMs/services.
