# 03 - Azure Role-Based Access Control (RBAC) Architecture

Azure RBAC regulates **who** has access to Azure resources, **what** actions they can perform, and **at what scope**.

Core Built-in Roles:
- **Owner**: Full access to all resources including access delegation.
- **Contributor**: Full access to create/manage resources (cannot delegate access).
- **Reader**: Read-only access to view resources.
