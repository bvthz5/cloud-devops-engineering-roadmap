# 09 - Interview Q&A: Azure Entra ID & RBAC

### Q: What is the main difference between System-Assigned and User-Assigned Managed Identities?
**Answer:** System-Assigned Managed Identity is tied 1-to-1 with a specific Azure resource and automatically deleted when the resource is deleted. User-Assigned is a standalone resource that can be shared across multiple resources and managed independently.
