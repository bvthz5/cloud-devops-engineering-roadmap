# 09 - Interview Q&A: Azure Arc

### Q: What is the primary purpose of Azure Arc?
**Answer:** Azure Arc extends Azure Resource Manager (ARM) governance, security (Defender for Cloud), and cloud service capabilities to resources running outside Azure (on-premises or in AWS/GCP).
