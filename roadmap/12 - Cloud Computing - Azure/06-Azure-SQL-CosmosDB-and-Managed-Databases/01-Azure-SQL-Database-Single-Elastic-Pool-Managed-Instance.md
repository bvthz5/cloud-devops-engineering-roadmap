# 01 - Azure SQL Database & Managed Instance

- **Single Database**: Fully managed PaaS SQL database with predictable performance (DTU or vCore model).
- **Elastic Pool**: Shared database pool for managing multiple databases with variable demand.
- **SQL Managed Instance**: 100% compatible SQL Server instance with native VNet integration.
