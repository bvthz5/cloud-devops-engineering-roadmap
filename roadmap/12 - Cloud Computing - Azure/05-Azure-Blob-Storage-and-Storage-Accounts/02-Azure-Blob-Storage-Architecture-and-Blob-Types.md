# 02 - Azure Blob Storage Architecture

- **Block Blobs**: Optimized for storing text/binary files (up to 190.7 TB per blob).
- **Append Blobs**: Optimized for append operations (e.g. logging).
- **Page Blobs**: Optimized for random read/write operations (used by Azure VM VHD disks).
- **Data Lake Storage Gen2 (ADLS Gen2)**: Hierarchical namespace on Blob storage for analytics.
