# 01 - Storage Account Types & Redundancy Options

- **Locally Redundant Storage (LRS)**: 3 copies within a single datacenter.
- **Zone-Redundant Storage (ZRS)**: 3 copies across 3 Availability Zones in the primary region.
- **Geo-Redundant Storage (GRS)**: 6 copies across primary and paired secondary regions (async).
- **Read-Access Geo-Redundant Storage (RA-GRS)**: Read access to secondary region endpoint.
