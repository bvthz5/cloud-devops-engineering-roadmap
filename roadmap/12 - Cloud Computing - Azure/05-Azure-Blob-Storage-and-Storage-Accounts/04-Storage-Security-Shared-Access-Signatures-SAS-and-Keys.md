# 04 - Shared Access Signatures (SAS) & Security

A Shared Access Signature (SAS) provides delegated URI access to storage resources with specified permissions, start time, and expiration.

- **User Delegation SAS**: Secured with Entra ID credentials (best practice).
- **Service SAS**: Secured with Storage Account Access Keys.
