# 09 - Interview Q&A: Azure Storage

### Q: Why is a User Delegation SAS preferred over a Service SAS?
**Answer:** User Delegation SAS is signed using Microsoft Entra ID credentials rather than Storage Account shared keys, allowing fine-grained audit logging and RBAC revocation.
