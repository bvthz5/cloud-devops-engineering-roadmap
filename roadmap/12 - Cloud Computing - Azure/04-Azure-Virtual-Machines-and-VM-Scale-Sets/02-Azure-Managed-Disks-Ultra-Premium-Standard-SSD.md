# 02 - Azure Managed Disks

- **Ultra Disk**: Top-tier performance for I/O intensive databases (up to 160,000 IOPS).
- **Premium SSD (`P4-P80`)**: High-performance SSD storage for enterprise workloads.
- **Ephemeral OS Disk**: OS disk stored on local VM host storage (zero storage cost & faster re-image).
