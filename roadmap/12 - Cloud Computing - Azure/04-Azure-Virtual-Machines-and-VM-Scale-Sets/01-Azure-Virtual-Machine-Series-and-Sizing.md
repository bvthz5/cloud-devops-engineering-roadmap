# 01 - Azure Virtual Machine Series

- **B-Series**: Burstable CPU performance for web servers and light dev workloads.
- **D-Series**: General purpose compute and memory ratio.
- **E-Series**: Memory-optimized for in-memory caches and databases.
- **F-Series**: Compute-optimized for batch processing and analytics.
