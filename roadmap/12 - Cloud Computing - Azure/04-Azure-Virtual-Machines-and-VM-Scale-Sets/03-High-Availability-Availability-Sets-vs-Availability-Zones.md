# 03 - Availability Sets vs Availability Zones

- **Availability Set**: Protects against hardware failures within a single datacenter using Fault Domains (FD) and Update Domains (UD) (SLA: 99.95%).
- **Availability Zone**: Protects against entire datacenter facility failure across physically separated zones (SLA: 99.99%).
