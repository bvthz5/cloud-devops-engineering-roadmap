# 09 - Interview Q&A: Azure Compute

### Q: What is the SLA difference between Availability Sets and Availability Zones in Azure?
**Answer:** Availability Sets guarantee 99.95% VM availability SLA within a single datacenter. Availability Zones guarantee 99.99% VM availability SLA across physically isolated datacenters.
