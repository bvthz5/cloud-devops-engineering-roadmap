# 18. MCQs and Quick Revision

1. What filesystem format is mandatory for the EFI System Partition (ESP)?
   - A. ext4
   - B. XFS
   - C. FAT32 (vfat)
   - D. Btrfs
   **Answer: C**

2. Which command resizes an online `ext4` filesystem?
   - A. `xfs_growfs`
   - B. `resize2fs`
   - C. `fsck.ext4`
   - D. `gparted`
   **Answer: B**

3. What `umask` setting provides hardened default security permissions (`640` files / `750` dirs)?
   - A. `000`
   - B. `022`
   - C. `027`
   - D. `777`
   **Answer: C**
