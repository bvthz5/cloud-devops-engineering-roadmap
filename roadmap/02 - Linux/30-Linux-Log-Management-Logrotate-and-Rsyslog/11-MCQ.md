# 11 — Multiple Choice Questions: Log Management

---

### Q1. Which logrotate flag allows you to test rotation syntax without modifying any files on disk?
- [ ] A) `-f`
- [ ] B) `-d`
- [ ] C) `-t`
- [ ] D) `-s`

<details>
<summary><b>View Answer</b></summary>
<b>Correct Answer: B</b><br>
<code>-d</code> activates debug mode, simulating rotation decisions without making changes.
</details>
