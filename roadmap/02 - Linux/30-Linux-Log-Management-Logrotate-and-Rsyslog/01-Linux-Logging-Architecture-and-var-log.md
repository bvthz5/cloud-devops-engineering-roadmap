# 01 — Linux Logging Architecture and /var/log

Linux logging is traditionally governed by the **Syslog protocol** (RFC 5424). Messages generated by the kernel, daemons, and applications are tagged with a **Facility** (origin) and a **Severity** (urgency).

---

## 1. Syslog Facilities & Severities

### Facilities (Where the log originated):
`auth`, `authpriv`, `cron`, `daemon`, `kern`, `lpr`, `mail`, `syslog`, `user`, `local0` through `local7`.

### Severities (Priority level):
| Numerical Code | Severity | Description |
| :---: | :--- | :--- |
| **0** | `Emergency` (`emerg`) | System is unusable (kernel panic). |
| **1** | `Alert` (`alert`) | Action must be taken immediately (corrupted DB). |
| **2** | `Critical` (`crit`) | Critical hardware or software failure. |
| **3** | `Error` (`err`) | Non-urgent operational errors. |
| **4** | `Warning` (`warning`) | Warning conditions; potential future errors. |
| **5** | `Notice` (`notice`) | Normal but significant conditions. |
| **6** | `Informational` (`info`)| Normal operational messages. |
| **7** | `Debug` (`debug`) | Verbose debugging messages. |

---

## 2. Standard `/var/log/` Structure

| Log File | Distribution | Purpose |
| :--- | :--- | :--- |
| `/var/log/auth.log` | Debian / Ubuntu | Authentication logs, SSH logins, `sudo` execution |
| `/var/log/secure` | RHEL / Rocky | Same as auth.log on Red Hat systems |
| `/var/log/syslog` | Debian / Ubuntu | General system messages and unclassified daemon logs |
| `/var/log/messages` | RHEL / Rocky | Same as syslog on Red Hat systems |
| `/var/log/dmesg` | All distributions | Hardware detection logs during kernel boot |
| `/var/log/journal/` | systemd distributions| Binary persistent logs for `systemd-journald` |
