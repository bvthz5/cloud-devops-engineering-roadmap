# 06 - System Utilities & Binaries

System Utilities are essential command-line tools provided by the operating system distribution to enable users, scripts, and system daemons to manage files, inspect system state, and control running processes.

---

## 🛠️ Categories of System Utilities

### 1. GNU Coreutils (`coreutils`)
The foundational command utilities built into almost every Linux distribution:
- **File Utilities:** `ls`, `cp`, `mv`, `rm`, `cat`, `mkdir`, `chmod`, `chown`, `touch`, `ln`.
- **Text Utilities:** `head`, `tail`, `wc`, `sort`, `uniq`, `tr`, `cut`.
- **System Metrics:** `pwd`, `whoami`, `id`, `uname`, `date`.

### 2. Process & System Monitoring Utilities
- `ps`: Snapshot of active processes.
- `top` / `htop`: Dynamic real-time process viewer.
- `kill` / `pkill`: Send termination signals (`SIGTERM`, `SIGKILL`) to processes.

### 3. System Initialization & Service Control
- `systemctl`: Manage `systemd` background service daemons (start, stop, status).
- `journalctl`: Query binary logs generated by `systemd-journald`.

---

## 🔍 Locating Binary Utilities (`type`, `which`, `whereis`)

```bash
# Locate the path of an executable binary
which ls
# Output: /usr/bin/ls

# Determine if a command is a shell built-in or an external executable binary
type cd
# Output: cd is a shell builtin

type ls
# Output: ls is aliased to `ls --color=auto`
type -a ls
# Output: ls is /usr/bin/ls
```
