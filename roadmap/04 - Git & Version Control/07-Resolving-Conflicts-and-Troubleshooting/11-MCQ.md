# 11 - Resolving Conflicts: Self-Assessment MCQs

### Q1. Which command uses binary search to identify which commit introduced a bug?
- A) `git find-bug`
- B) `git bisect`
- C) `git blame`
- D) `git trace`
<details><summary><b>View Answer</b></summary><b>Correct Answer: B</b><br>`git bisect` automates binary search debugging between good and bad commits.</details>

### Q2. Which setting reveals the original common ancestor inside conflict markers?
- A) `merge.tool kdiff3`
- B) `merge.conflictstyle diff3`
- C) `diff.algorithm histogram`
- D) `rerere.enabled true`
<details><summary><b>View Answer</b></summary><b>Correct Answer: B</b><br>`merge.conflictstyle diff3` adds the `|||||||` common ancestor block.</details>
