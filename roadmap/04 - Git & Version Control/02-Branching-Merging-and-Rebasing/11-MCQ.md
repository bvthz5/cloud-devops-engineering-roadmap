# 11 - Branching & Merging: Self-Assessment MCQs

### Q1. What happens during a Fast-Forward merge?
- A) A new merge commit is created with two parent references
- B) The target branch pointer is simply moved forward to the tip of the merged branch
- C) Git rebases all commits interactively
- D) Git creates a temporary branch in memory
<details><summary><b>View Answer</b></summary><b>Correct Answer: B</b><br>Fast-forward simply updates the pointer without creating a new merge commit.</details>

---

### Q2. Which interactive rebase command combines a commit into the previous one while DISCARDING its commit message?
- A) `squash`
- B) `fixup`
- C) `reword`
- D) `drop`
<details><summary><b>View Answer</b></summary><b>Correct Answer: B</b><br>`fixup` squashes changes into the previous commit and discards the fixup commit message.</details>
