# 10 - Hands-On Practice: Git LFS Tracking and Pointer Inspection

## Lab Scenario
Install Git LFS, configure tracking for `.bin` files, create a mock binary file, and inspect the underlying pointer generated by Git LFS.

---

## Lab Steps

### Step 1: Initialize Git and Git LFS
```bash
mkdir /tmp/lfs-lab && cd /tmp/lfs-lab && git init
git lfs install
```

### Step 2: Track Binary Extension
```bash
git lfs track "*.bin"
git add .gitattributes
git commit -m "chore: track binary files with lfs"
```

### Step 3: Create a Mock Binary File
```bash
# Generate 5MB mock binary file
dd if=/dev/urandom of=model_weights.bin bs=1M count=5
git add model_weights.bin
git commit -m "feat: add model weights"
```

### Step 4: Inspect the Underlying Git Pointer
```bash
# Read the raw Git blob committed in the repository (not the smudged file):
git cat-file -p HEAD:model_weights.bin
# Notice the 3-line pointer with version, oid sha256, and size!
```
