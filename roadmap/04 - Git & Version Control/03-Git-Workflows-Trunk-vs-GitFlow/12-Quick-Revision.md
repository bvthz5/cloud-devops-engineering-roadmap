# 12 - Git Workflows: Quick Revision Cheat Sheet

## Workflow Summary Matrix

| Workflow | Branch Lifespan | Release Model | Complexity |
|---|---|---|---|

| **GitLab Flow** | Days to Weeks | Downstream environment promotion | Moderate |
