# 11 - Git Workflows: Self-Assessment MCQs

### Q1. According to DORA research, which branching strategy is a key technical practice of elite engineering performers?
- A) GitFlow
- B) Trunk-Based Development
- C) Forking Workflow
- D) Subversion Central Locking
<details><summary><b>View Answer</b></summary><b>Correct Answer: B</b><br>Trunk-Based Development is statistically linked to high deployment frequency and software delivery performance.</details>

### Q2. In Semantic Versioning (v2.1.4), what does an increment to the MINOR version indicate?
- A) Incompatible, breaking changes
- B) Backward-compatible bug fix
- C) Backward-compatible new functionality
- D) Security patch only
<details><summary><b>View Answer</b></summary><b>Correct Answer: C</b><br>MINOR signifies backward-compatible new functionality added to the codebase.</details>
