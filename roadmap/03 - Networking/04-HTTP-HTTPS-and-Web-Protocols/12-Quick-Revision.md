# 12 — Quick Revision Cheat Sheet: HTTP Protocols

---

## 1. Quick Reference

- **200 OK:** Success | **201 Created:** Resource created | **204 No Content:** Success without body
- **301:** Permanent Redirect (Cached) | **302:** Temporary Redirect | **304:** Not Modified (Cache Hit)
- **401:** Unauthorized (No auth) | **403:** Forbidden (Forbidden permissions) | **429:** Rate Limited
- **502:** Bad Gateway (Backend down) | **504:** Gateway Timeout (Backend slow)
