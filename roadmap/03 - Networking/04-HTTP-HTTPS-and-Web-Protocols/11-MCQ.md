# 11 — Multiple Choice Questions: HTTP Protocols

---

### Q1. Which underlying transport protocol is used by HTTP/3?
- [ ] A) TCP
- [ ] B) QUIC over UDP
- [ ] C) SCTP
- [ ] D) Raw IP

<details>
<summary><b>View Answer</b></summary>
<b>Correct Answer: B</b><br>
HTTP/3 replaces TCP with QUIC, running over UDP to eliminate Head-of-Line blocking.
</details>
