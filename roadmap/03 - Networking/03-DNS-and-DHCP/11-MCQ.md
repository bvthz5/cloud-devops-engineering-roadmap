# 11 — Multiple Choice Questions: DNS & DHCP

---

### Q1. Which UDP port is used by a DHCP client to send requests to a DHCP server?
- [ ] A) Port 53
- [ ] B) Port 67
- [ ] C) Port 68
- [ ] D) Port 80

<details>
<summary><b>View Answer</b></summary>
<b>Correct Answer: C</b><br>
DHCP clients use UDP port 68; DHCP servers listen on UDP port 67.
</details>
