### Question 1
Which open-source policy-as-code engine uses simple YAML files to filter and automate remediation actions (such as deleting idle disks) across AWS, Azure, and GCP?
- [ ] A) Terraform
- [x] B) Cloud Custodian
- [ ] C) Infracost
- [ ] D) OpenTelemetry

*Explanation: Cloud Custodian is a stateless open-source rules engine for cloud resource management and waste remediation.*

### Question 2
What is the primary role of an OpenTelemetry Collector Receiver?
- [ ] A) To render Grafana dashboards
- [x] B) To ingest telemetry data (traces, metrics, logs) from applications or agents
- [ ] C) To delete unattached cloud storage volumes
- [ ] D) To manage IAM user credentials

*Explanation: Receivers in OTel Collector define how telemetry data enters the collector pipeline (e.g., OTLP gRPC, Prometheus).*

### Question 3
How does Terragrunt reduce code duplication (DRY principle) in Terraform projects?
- [ ] A) By replacing HCL code with Python
- [x] B) By allowing remote backend and provider configurations to be defined once in a root configuration file and inherited across modules
- [ ] C) By automatically executing AWS Savings Plan purchases
- [ ] D) By converting CloudFormation templates to YAML

*Explanation: Terragrunt eliminates copy-pasted backend configurations and environment variables across Terraform modules.*
