# 11 - MCQ: Security & Debugging

#### Q1. Which parameter forces Ansible to drop into an interactive debug shell when a task fails?
- [ ] A) `debug: true`
- [x] B) `debugger: on_failed`
- [ ] C) `on_error: debug`
- [ ] D) `catch_error: interactive`

<details><summary>Explanation</summary>`debugger: on_failed` activates the interactive debugger CLI when a task fails.</details>
