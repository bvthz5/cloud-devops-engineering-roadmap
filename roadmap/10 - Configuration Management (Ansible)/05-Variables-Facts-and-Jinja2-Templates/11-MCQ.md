# 11 - MCQ: Variables & Templates

#### Q1. Which Jinja2 filter provides a default value if a variable is undefined?
- [ ] A) `| fallback('val')`
- [x] B) `| default('val')`
- [ ] C) `| coalesce('val')`
- [ ] D) `| nvl('val')`

<details><summary>Explanation</summary>The `default()` filter supplies a fallback string if the variable is not defined.</details>
