# 11 - MCQ: Ansible CI/CD

#### Q1. Which Ansible flag displays differences in files during a dry run?
- [ ] A) `--show-changes`
- [x] B) `--check --diff`
- [ ] C) `--dry-run --verbose`
- [ ] D) `--test-mode`

<details><summary>Explanation</summary>`--check` performs a dry-run and `--diff` prints unified file diffs.</details>
