# 03 - File & Directory Modules

## Key Modules
- `file`: Create directories, symlinks, manage permissions (`state=directory`, `state=touch`).
- `copy`: Copy files from control node to managed node.
- `lineinfile`: Ensure a specific line exists or is replaced in a file using regex.
- `blockinfile`: Insert/update/remove a multi-line block of text surrounded by marker lines.
