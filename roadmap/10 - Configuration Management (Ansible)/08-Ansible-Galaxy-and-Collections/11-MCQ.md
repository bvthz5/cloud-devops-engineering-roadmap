# 11 - MCQ: Galaxy & Collections

#### Q1. Which CLI command installs dependencies listed in `requirements.yml`?
- [x] A) `ansible-galaxy install -r requirements.yml`
- [ ] B) `ansible-pip install requirements.yml`
- [ ] C) `ansible-playbook --requirements requirements.yml`
- [ ] D) `ansible-collections get requirements.yml`

<details><summary>Explanation</summary>`ansible-galaxy install -r` reads requirements.yml to install roles and collections.</details>
