# 12 - Quick Revision: Playbook Keywords Cheat Sheet

- `notify`: Triggers a handler if task status is changed.
- `when`: Conditional task execution.
- `loop`: Iterates over list or dict.
- `block/rescue/always`: Error handling mechanism.
