# 09 - Interview Q&A: Roles & Directory Structure

### Q: What is the main difference between `import_tasks` and `include_tasks`?
**Answer:** `import_tasks` is static and evaluated when playbooks are parsed. `include_tasks` is dynamic and evaluated at runtime when the task is reached.
