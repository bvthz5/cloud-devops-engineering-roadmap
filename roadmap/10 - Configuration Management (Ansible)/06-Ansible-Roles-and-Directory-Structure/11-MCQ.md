# 11 - MCQ: Ansible Roles

#### Q1. Which directory in an Ansible role holds variables with the LOWEST precedence?
- [x] A) `defaults/`
- [ ] B) `vars/`
- [ ] C) `meta/`
- [ ] D) `tasks/`

<details><summary>Explanation</summary>Variables in `defaults/main.yml` have the lowest priority (Level 1) so they can be easily overridden.</details>
