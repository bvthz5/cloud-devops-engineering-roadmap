# 12 - GitHub Collaboration: Quick Revision Cheat Sheet

## Remote Commands Cheat Sheet

| Command | Action |
|---|---|
| `git remote -v` | List all configured remotes with URLs |
| `git remote add upstream <url>` | Add upstream reference |
| `git fetch upstream` | Download new objects from upstream safely |
| `git push --force-with-lease` | Safe force-push after interactive rebase |
| `git push -u origin <branch>` | Push branch and set upstream tracking |
| `git branch -r` | List all remote-tracking branches |
