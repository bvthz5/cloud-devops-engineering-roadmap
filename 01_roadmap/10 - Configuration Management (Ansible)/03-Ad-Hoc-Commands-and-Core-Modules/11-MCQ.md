# 11 - MCQ: Core Modules

#### Q1. Which module can run on a managed node that has NO Python installed?
- [ ] A) `ansible.builtin.command`
- [ ] B) `ansible.builtin.shell`
- [x] C) `ansible.builtin.raw`
- [ ] D) `ansible.builtin.script`

<details><summary>Explanation</summary>The `raw` module executes low-level SSH commands directly without invoking Python on target.</details>
