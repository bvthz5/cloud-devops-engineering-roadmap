# 06 - Utility Modules: ping, uri, get_url, stat

- `ansible.builtin.ping`: Verify Python and SSH execution on target.
- `ansible.builtin.uri`: Interact with REST APIs.
- `ansible.builtin.get_url`: Download files via HTTP/HTTPS/FTP.
- `ansible.builtin.stat`: Inspect file status and attributes.
