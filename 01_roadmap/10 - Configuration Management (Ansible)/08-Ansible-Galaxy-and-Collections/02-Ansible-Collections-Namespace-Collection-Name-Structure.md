# 02 - Ansible Collections Architecture (`namespace.collection`)

Collections package roles, modules, plugins, and doc fragments into a single versioned artifact.

```text
my_namespace/
└── my_collection/
    ├── galaxy.yml
    ├── plugins/
    │   └── modules/
    └── roles/
```
