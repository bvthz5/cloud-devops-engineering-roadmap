# 11 - MCQ: Inventory Management

#### Q1. Which extension MUST an Ansible AWS EC2 inventory plugin file end with?
- [x] A) `aws_ec2.yml` or `aws_ec2.yaml`
- [ ] B) `aws.json`
- [ ] C) `inventory.ini`
- [ ] D) `ec2.py`

<details><summary>Explanation</summary>Ansible inventory plugins require specific naming conventions ending in `aws_ec2.yml` or `aws_ec2.yaml` to trigger the plugin loader.</details>
