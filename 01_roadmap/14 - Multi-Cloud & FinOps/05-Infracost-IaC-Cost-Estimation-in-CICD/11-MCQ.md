### Question 1
Which AWS pricing model provides the highest flexibility for discount application across EC2, Fargate, and Lambda based on hourly spend commitments?
- [ ] A) Standard Reserved Instances
- [x] B) Compute Savings Plans
- [ ] C) Spot Instances
- [ ] D) On-Demand Capacity Reservations

*Explanation: Compute Savings Plans apply automatically across EC2, Fargate, and Lambda regardless of region, instance family, or OS.*

---

### Question 2
What protocol is used by Workload Identity Federation to exchange tokens between multi-cloud identity providers?
- [ ] A) BGP
- [ ] B) IPsec
- [x] C) OpenID Connect (OIDC) / OAuth 2.0
- [ ] D) SNMP

*Explanation: OIDC token exchange allows workloads in one platform to prove identity to another cloud provider without static credentials.*

---

### Question 3
What notice period do AWS EC2 Spot Instances and GCP Spot VMs provide before terminating an instance due to capacity demands?
- [ ] A) 15 minutes
- [x] B) 2 minutes (120 seconds)
- [ ] C) 1 hour
- [ ] D) No advance notice is provided

*Explanation: Cloud providers provide a 2-minute (120-second) warning notification prior to evicting Spot instances.*
