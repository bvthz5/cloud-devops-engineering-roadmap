# SOURCE

Original supplied material for Topic 18 (Linux Server Hardening):

Linux Server Hardening is the practice of securing a system by reducing its attack surface, eliminating unnecessary software/services, enforcing strict access controls, tuning kernel parameters, and setting up continuous monitoring.

CRITICAL WARNING:
Always test SSH configuration changes and firewall rule updates in a non-production test environment or keep an open active SSH session during changes. Misconfigured SSH or firewall rules can permanently lock administrators out of remote servers.
