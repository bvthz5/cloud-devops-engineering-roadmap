# 11 — Multiple Choice Questions: SSH Architecture

---

### Q1. What does `ssh -N` do?
- [ ] A) Disables network compression
- [ ] B) Instructs SSH not to execute a remote shell command (useful for port forwarding only)
- [ ] C) Connects with no authentication
- [ ] D) Forces IPv6

<details>
<summary><b>View Answer</b></summary>
<b>Correct Answer: B</b><br>
`-N` tells SSH not to execute a remote command or open a shell, which is standard when running tunnels.
</details>
