# 10 - Hands-On Practice Labs

## Lab: Import and Refactor

1. Create an AWS resource manually via Console
2. Write an import block for it
3. Run `terraform plan -generate-config-out=imported.tf`
4. Clean up generated code
5. Apply to bring under Terraform management
6. Use a `moved` block to rename the resource
