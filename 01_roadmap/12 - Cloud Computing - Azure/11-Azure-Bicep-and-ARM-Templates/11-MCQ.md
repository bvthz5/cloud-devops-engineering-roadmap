# 11 - MCQ: Azure Bicep

#### Q1. Which CLI command converts an existing ARM JSON template into a Bicep file?
- [ ] A) `bicep convert`
- [x] B) `az bicep decompile`
- [ ] C) `bicep parse`
- [ ] D) `az bicep import`

<details><summary>Explanation</summary>`az bicep decompile` decompiles ARM JSON templates into Bicep source code.</details>
