# 12 - Quick-Revision & Enterprise Cheat Sheet

## CRD & Operator Cheat Sheet

- **CRD:** Defines new API schema (Group, Version, Kind, OpenAPI v3 validation).
- **Operator:** Controller written in Go (Kubebuilder) or Python/Ansible that executes automated operational tasks.
- **Reconciliation:** Level-triggered loop comparing Desired State with Actual State.
- **Finalizers:** Prevents deletion until external cloud resources are cleaned up.
