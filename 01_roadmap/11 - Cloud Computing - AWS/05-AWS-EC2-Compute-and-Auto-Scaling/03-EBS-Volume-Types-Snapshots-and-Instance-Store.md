# 03 - EBS Volume Types & Instance Store

- **General Purpose SSD (`gp3`)**: Baseline IOPS independent of storage volume size.
- **Provisioned IOPS SSD (`io2`)**: High performance mission-critical database storage.
- **Instance Store**: Ephemeral physical block storage directly attached to host server (data lost on stop/terminate).
