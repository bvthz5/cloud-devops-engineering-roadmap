# 11 - Multiple Choice Practice Questions (Certification Exam Level)

---

### 1. Under the AWS Shared Responsibility Model, which task is the sole responsibility of the customer when running an Amazon EC2 instance?
- [ ] A) Physical security of the datacenter hosting the server
- [ ] B) Patching the underlying hypervisor operating system
- [x] C) Installing security patches on the guest operating system
- [ ] D) Replacing defective hard drives in the host server rack
> **Explanation:** For EC2 (IaaS), AWS manages the physical server and hypervisor. The customer is 100% responsible for the guest OS patching and software dependencies.

---

### 2. Which cloud computing benefit allows an organization to automatically match resource supply with fluctuating demand in real time?
- [ ] A) High Availability
- [x] B) Rapid Elasticity
- [ ] C) Fault Tolerance
- [ ] D) Data Durability
> **Explanation:** Rapid Elasticity allows resources to dynamically stretch out during traffic spikes and contract back during idle periods.

---

### 3. Which AWS pricing model provides the highest percentage discount (up to 90%) for fault-tolerant batch workloads?
- [ ] A) On-Demand Instances
- [ ] B) Standard Reserved Instances
- [x] C) Spot Instances
- [ ] D) Dedicated Hosts
> **Explanation:** Spot Instances leverage spare AWS capacity at up to 90% discount, with a 2-minute interruption notice.
