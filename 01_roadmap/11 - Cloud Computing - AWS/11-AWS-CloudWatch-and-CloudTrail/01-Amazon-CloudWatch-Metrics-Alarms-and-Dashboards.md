# 01 - Amazon CloudWatch Metrics & Alarms

CloudWatch collects raw performance metrics from AWS services (CPU, Network, Disk I/O).

- **Metric**: Time-series data point pair (Timestamp, Value).
- **Alarm**: Evaluates metric over specified period and triggers actions (SNS, ASG scaling, EC2 reboot).
