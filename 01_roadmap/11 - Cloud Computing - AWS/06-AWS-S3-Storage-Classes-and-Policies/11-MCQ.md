# 11 - MCQ: AWS S3

#### Q1. Which S3 storage class automatically moves objects between access tiers based on changing usage patterns?
- [ ] A) S3 Standard-IA
- [x] B) S3 Intelligent-Tiering
- [ ] C) S3 Glacier Flexible
- [ ] D) S3 One Zone-IA

<details><summary>Explanation</summary>S3 Intelligent-Tiering monitors access patterns and moves objects to cheaper tiers without operational overhead or retrieval fees.</details>
