# 12 — Loops: For, While, Until, and Case

## 1. Loop Syntax
- `for item in "${list[@]}"; do ... done`
- `while read -r line; do ... done < file.txt`
- `until [[ condition ]]; do ... done`
- `case "$var" in pattern) ... ;; esac`
