# Topic 17 — Cron Jobs in Linux

## Objective
Learn how Linux schedules commands and scripts automatically using `cron` and `crontab`.

## What this topic covers
- Cron and cron jobs
- User crontabs
- Five-field cron syntax
- `*`, `,`, `-`, `/`
- Special shortcuts such as `@daily` and `@reboot`
- Writing, testing, disabling, and removing jobs
- Absolute paths and cron's minimal environment
- Output/error redirection and logging
- Cron service and log troubleshooting
- System-wide cron locations
- Security and reliability practices
- `cron` vs `anacron` vs `systemd timers` vs Kubernetes CronJobs
- Hands-on exercises
- Scenario-based troubleshooting
- Interview questions and MCQs
