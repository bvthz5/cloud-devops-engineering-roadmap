# 22. MCQs & Quick Revision Quiz

1. Which location modifier in Nginx has the highest matching precedence?
   - A. `~`
   - B. `~*`
   - C. `=`
   - D. `^~`
   **Answer: C** (Exact match `=` has priority 1).

2. Which Apache MPM uses asynchronous listeners to handle Keep-Alive connections efficiently?
   - A. Prefork
   - B. Worker
   - C. Event
   - D. Perchild
   **Answer: C**

3. What HTTP header informs a backend application server of the client's original protocol (HTTP vs HTTPS)?
   - A. `X-Real-IP`
   - B. `X-Forwarded-Proto`
   - C. `Host`
   - D. `X-Forwarded-Host`
   **Answer: B**

4. Which web server features automatic HTTPS certificate generation out of the box without Certbot?
   - A. Nginx
   - B. Apache HTTPd
   - C. Caddy
   - D. lighttpd
   **Answer: C**
