# 07 — File, String, and Numeric Tests

## 1. Test Operators Syntax
- Preferred: Double bracket `[[ ... ]]` keyword.

## 2. File Operators
- `-f file`: Regular file exists.
- `-d dir`: Directory exists.
- `-e path`: Path exists.
- `-s file`: File exists and size > 0 bytes.
- `-x file`: Executable file.

## 3. String & Numeric Operators
- `-z str`: Empty string.
- `-n str`: Non-empty string.
- `str1 == str2`: Equal strings.
- `-eq`, `-ne`, `-gt`, `-ge`, `-lt`, `-le`: Integer comparisons.
